# FootyGuess ⚽

A Flutter app of football guessing games, backed by a clean dataset of real
historic football data (players, matches, lineups, careers).

## 🎮 Games

| Game | Description | Data source |
|---|---|---|
| **Guess the Player** | Wordle-style: guess the mystery player from nationality, club, league, position, age | `players.json` |
| **Career Path** | Guess the player as their club career is revealed | `players.json` (career history) |
| **Who Scored?** | Guess the score and scorers of a historic match | `matches.json` |
| **Tenable** | Top-N list challenges (top scorers, most appearances…) | `tenable.json` |
| **Missing XI** | Rebuild a real starting XI in formation | `lineups.json` |

Plus **Leaderboard** and **Profile** screens.

## 🏗️ Architecture

```
app/lib/
├── core/                 # Theme, environment, data providers
│   ├── providers/game_data_providers.dart   # Riverpod data providers
│   └── theme/            # Modern glassmorphic theme (+ legacy themes)
├── data/
│   ├── models/game_data_models.dart         # Canonical models (GamePlayer, GameMatch…)
│   └── services/game_data_service.dart      # Loads the canonical JSON files
├── features/             # One folder per game (pages + providers)
├── routing/              # GoRouter
└── widgets/              # Shared UI
```

### Data layer

There is **one** source of truth: `app/assets/data/` (5 canonical JSON files),
loaded by `GameDataService` and exposed through Riverpod providers.

```
data_pipeline/            # Python collection pipeline
└── build.py              #   -> app/assets/data/{players,matches,lineups,clubs,tenable}.json
```

See [data_pipeline/README.md](data_pipeline/README.md) for sources, schema and
how to re-collect / extend the data.

## 📦 Data at a glance

Generated by the pipeline from StatsBomb Open Data, TheSportsDB, and curated
CSVs:

- **~5,900 players** (with age, nationality, position, club, and career history for many)
- **~2,300 historic matches** (1,500 with full scorer + minute data)
- **~4,400 real starting XIs** with formations
- **~270 clubs**
- **37 Tenable categories** (top scorers per competition/season, most appearances, …)

## 🔧 Re-collecting data

```bash
cd data_pipeline
python3 build.py --max-events 500      # more Who Scored matches
python3 build.py --skip-thesportsdb    # skip the rate-limited API
```

## ⚠️ Status

- Firebase / backend integration is **not implemented** (dependencies are disabled).
- Scoring and leaderboards are client-side placeholders.
- The UI theme is in transition: home + Guess the Player use the modern light
  theme; other screens still use the older dark theme.
